# 后续计划

LitTrace 已经实现了引文定位、来源追溯、流式进度和阶段恢复。下一阶段的重点是语义能力：让系统不只找到原文，还能判断原文是否真正支持报告中的结论。

## 评测协议

先构建带来源版本、原文范围、任务条件和人工标注规则的样本，划分开发集和独立测试集，并提前确定样本规模、调用预算和终止条件。复合论断拆分成子命题后，单独统计指标，保证前后结果可比。

## 研究方向

| 方向 | 假设与可观察预期 | 验证方法 | 判定标准 |
| --- | --- | --- | --- |
| 条件匹配 | 显式区分任务、模型、预算、指标和术语含义，可减少把 prefill chunk 当成检索 chunk 这类错配 | 固定候选材料，比较现有与新条件判断；覆盖不匹配、可比、缺信息三类；报告混淆矩阵和正确支持的保留情况 | 错误支持减少，同时可比证据的召回不下降 |
| 原子论断拆分 | 把复合命题拆成保留限定词的子命题，可减少部分支持被上推为完整支持 | 人工检查拆分是否丢失条件或改变范围；分别评估子命题和整体结论 | 子命题与整体结论的证据覆盖同时提升 |
| 支持关系判断 | 结合具体结果与条件、区分方法描述和实验证据，可减少 neutral / inconclusive 被标为 supports | 在同一批冻结材料和候选边上，比较支持精确率、错误支持数、支持检出率、弃权率和成本 | 精确率提升，同时弃权率和成本保持在可接受范围 |

每次实验记录基线、调用预算、模型和提示词版本，方便复现与对比。

## 工程改进

- `replay_frozen_material.py` 的 `source_mutations` 改用稳定的 source_id 或 URL + version + excerpt_hash 作为键，支持同一来源多个片段的独立回放，并补充对应回归用例。
- 统一 `citation_coverage` 的对外名称为定位正确率，同时兼容已有的评分产物。
