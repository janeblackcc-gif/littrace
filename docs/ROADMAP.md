# 后续计划

当前版本完成的是限定 AI/CS 场景的工程 MVP：引文定位、来源追溯、流式进度和阶段恢复已有实现与回归脚本。下面三项属于语义能力改进，尚未开始实验，也没有已验证的提升数字。

## 先固定评估协议

另建带来源版本、原文范围、任务条件和人工标注规则的样本，分别划定开发集和不参与调参的测试集。规模、调用预算和停止条件在实施前确定。复合论断拆成多个子命题后，不与原有分母直接比较。

## 按假设推进

| 方向 | 假设与可观察预期 | 验证方法 | 停止或回退依据 |
| --- | --- | --- | --- |
| 条件匹配 | 显式区分任务、模型、预算、指标和术语含义，可减少把 prefill chunk 当成检索 chunk 这类错误 | 固定候选材料，比较现有与新条件判断；覆盖不匹配、可比、缺信息三类；报告混淆矩阵和正确支持的保留情况 | 只增加 unknown 而没有减少错误支持，或误拒可比证据时，不宣称有效 |
| 原子论断拆分 | 把复合命题拆成保留限定词的子命题，可减少部分支持被上推为完整支持 | 人工检查拆分是否丢失条件或改变范围；分别评估子命题和整体结论 | 不用拆分后的较高分数掩盖完整命题仍缺证据 |
| 支持关系判断 | 结合具体结果与条件、区分方法描述和实验证据，可减少 neutral / inconclusive 被标为 supports | 在同一批冻结材料和候选边上，比较支持精确率、错误支持数、支持检出率、弃权率和成本 | 不用全部弃权换取表面精确率；没有支持正例时记为 N/A |

公平基线、调用预算、模型和提示词版本都要记录。

## 维护项

- `replay_frozen_material.py` 的 `source_mutations` 只以 URL 为键，同一版本不同片段的摘要会互相覆盖。计划改用稳定的 source_id 或 URL + version + excerpt_hash，并补充同 URL、不同片段的回归用例。
- `citation_coverage` 对外统一称为定位正确率；以后如重命名，需要兼容旧的评分产物。
